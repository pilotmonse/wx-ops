# WX OPS — Global Station Weather Dashboard

Live, single-page situational-awareness dashboard: METAR/TAF with flight categories (VFR/MVFR/IFR/LIFR), 3-day forecasts, satellite IR and precipitation radar layers, FAA NAS ground stops / ground delay programs / delays, U.S. State Department travel advisories and local news for a sample of worldwide cargo stations.

**Unofficial personal project — not affiliated with Atlas Air Worldwide. Not for flight planning or dispatch.**

Data: api.met.no (METAR/TAF), Open-Meteo, NWS api.weather.gov, NASA GIBS, EUMETSAT, RainViewer, Iowa Environmental Mesonet, FAA NAS Status, travel.state.gov, Bing News, GDELT. Map © MapTiler © OpenStreetMap contributors.
